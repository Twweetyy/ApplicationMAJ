# Lots d'exemple

Données publiques de l'INSEE (Licence Ouverte Etalab 2.0), réduites aux 38 IRIS de Roubaix.
Elles permettent d'essayer le portail sans télécharger les fichiers nationaux.

| Dossier | Millésime |
|---|---|
| `lot2022/` | données 2022 |
| `lot2023/` | données 2023 |

## Essayer

1. Lancer le portail (`run_portal.bat`), puis ouvrir la page indiquée.
2. Zone **Données** : déposer tous les fichiers de `lotXXXX/data/`.
3. Zone **Métadonnées** : déposer tous les fichiers de `lotXXXX/meta/`.
4. Cliquer sur **Analyser le lot**, puis sur **Exécuter le pipeline ETL**, et télécharger le classeur.

Source : INSEE, https://www.insee.fr
